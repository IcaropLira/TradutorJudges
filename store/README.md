# Imagens para as lojas

Todas geradas a partir de `icons/logo.svg` / `icons/icon.svg` (fontes: Playfair Display e Inter, como no portfólio).
`pt/` = listagem em português; `en/` = listagem em inglês (a tradução mostrada é para espanhol).

## Chrome Web Store
| Campo | Arquivo |
|---|---|
| Ícone da loja (128×128, arte de 96 px + 16 px de margem transparente) | `icons/chrome-store-icon-128.png` |
| Bloco promocional pequeno (440×280) — obrigatório | `pt/promo-small-440x280.png` ou `en/…` |
| Bloco promocional marquee (1400×560) — opcional | `pt/promo-marquee-1400x560.png` ou `en/…` |
| Capturas de tela (1280×800, até 5) | `pt/screenshot-1…5.png` / `en/screenshot-1…5.png` |

Os blocos promocionais não podem ser localizados na Chrome Web Store: escolha um idioma. As capturas podem ser enviadas por idioma.

## Firefox (addons.mozilla.org)
| Campo | Arquivo |
|---|---|
| Ícone | já vem no pacote; se pedir upload, use `icons/icon-128.png` |
| Capturas de tela (1280×800) | as mesmas `screenshot-*.png` |
